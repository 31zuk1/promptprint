# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

**Promptprint** — a browser-only, static React + TypeScript app that analyzes ChatGPT/Claude conversation exports locally and visualizes user-vs-AI vocabulary as a "Mirror Cloud" (user-dominant terms left, shared center, AI-dominant right). No backend, no accounts, no external runtime requests. All primary user-facing copy is Japanese.

`AGENTS.md` is the authoritative repository instruction file — read it before changing implementation code. Product behavior is defined in `docs/PRODUCT_SPEC.md`, implementation constraints in `docs/TECHNICAL_SPEC.md`, completion criteria in `docs/ACCEPTANCE.md`. Record meaningful decisions, milestones, and validation evidence in `docs/EXECPLAN.md`.

## Commands

Requires Node >= 22.12.0 and pnpm 11.19.0.

- `pnpm dev` — Vite dev server
- `pnpm check` — typecheck → lint → unit tests → build (does NOT include e2e)
- `pnpm typecheck` / `pnpm lint` — ESLint fails on warnings (`--max-warnings 0`)
- `pnpm test` — Vitest run once; `pnpm test:watch` for watch mode
- Single test file: `pnpm vitest run src/importers/chatgpt.test.ts`
- `pnpm e2e` — Playwright (Chromium only; auto-starts Vite on 127.0.0.1:4173). First-time setup: `pnpm exec playwright install chromium`
- `pnpm build` — outputs static bundle to `dist/`

## Architecture

Full details in `docs/ARCHITECTURE.md`. The big picture:

**Main thread ⇄ Worker split.** All parsing and analysis runs in a dedicated Web Worker (`src/workers/analysis.worker.ts`). The main thread (`src/App.tsx` reducer + `src/components/`) sends file ArrayBuffers or normalized demo conversations plus `AnalysisSettings`; the worker responds with staged progress, normalized conversations, statistics, insights, contexts, and layout. Message contract lives in `src/workers/protocol.ts`. Every request/response carries a monotonic `requestId`; the main thread accepts only the newest. Cancellation = terminating the worker (plus an operation-generation guard for un-abortable file reads), not cooperative checks.

**Pipeline flow.** ZIP inventory (`src/importers/zip.ts`, fflate) → provider detection (`src/importers/detect.ts`) → adapters (`src/importers/chatgpt.ts`, `src/importers/claude.ts` — Claude is deliberately experimental/conservative) → shared `NormalizedConversation`/`NormalizedMessage` model (`src/domain/models.ts`) → cleaning → tokenization (`Intl.Segmenter`) → phrases → statistics → echo/AI-first insights → deterministic SVG layout (`src/analysis/*`). Filter changes re-send the retained normalized corpus to the worker; files are never reparsed.

**Key invariants** (from AGENTS.md — do not weaken silently):
- Imported data stays in browser memory only. Never persist raw messages to localStorage/IndexedDB/cookies/caches; never add analytics, telemetry, remote fonts, or CDN scripts. `解析データを消去` must fully tear down worker, state, and object URLs.
- `originalText` (for context view) is kept separate from cleaned analysis text; cleaning never mutates it. Tokenization uses only cleaned text.
- Analysis and layout are deterministic for identical data + settings. No `Date.now()`/randomness in the pipeline.
- Statistics use message-document frequency and role-normalized rates; raw token counts break ties only. No causal claims about AI-first terms or value judgments about Echo rate.
- Demo conversations go through the exact same normalization/analysis path as imports.
- All import boundaries start from `unknown` with explicit type guards; JSON/ZIP is untrusted input with hard caps (see limits tables in README/`src/importers/limits.ts`). Failures are recoverable values with actionable Japanese messages, and diagnostics never leak raw source text or unknown key names.
- ChatGPT graph exports: follow the current branch only (via `current_node`), never aggregate all branches; fallback leaf selection is deterministic and diagnosed.
- PNG export draws a fresh Canvas from aggregate terms only — never original excerpts, titles, emails, or hidden terms.
- Preserve keyboard access: focusable SVG terms, Enter opens context, Escape closes and restores focus.

**Testing.** Unit tests (Vitest + jsdom) sit next to modules with fixtures in `src/test/fixtures/`. Playwright (`e2e/promptprint.spec.ts`) enforces the privacy guarantees at runtime: same-origin-only network, no console errors, empty storage after imports, and privacy checks on Canvas-drawn strings. The canonical screenshot artifact is `artifacts/promptprint-demo.png` (regenerated by `pnpm e2e` at 1440×1000).

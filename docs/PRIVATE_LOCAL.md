# Promptprint Private — 非公開・端末内だけの履歴取得

## 保存済み本文を新しい抽出エンジンで見る

個人用ビルドには日本語形態素辞書（圧縮約17.8 MB、展開約100 MB）と英語品詞モデルが同梱されています。辞書準備後、保存済み本文から名詞・名詞句を再抽出します。処理は専用Worker内だけで完結し、辞書の外部取得・外部AIへの本文送信・ChatGPTへの履歴追加取得は行いません。長い履歴の初回再解析には時間とメモリが必要です。

ビルド更新後は取得を停止したまま個人用ページを再読み込みしてください。保存した会話から自動で再解析します。「接続して取得を開始」「取得を再開」を押す必要はありません。表示条件・期間の変更でも保存済みデータを使います。辞書を読み込めない場合はエラーを表示し、不完全な旧抽出を代わりに表示しません。

## 2D / 3Dを切り替える

図の上部で「3D 分布」を選べます。X＝あなた／AIの使用傾向、Y＝役割別の発言出現率の均等平均、Z＝現在の対象会話に占めるカバー率です。「視点を操作」または余白のドラッグで回転し、「視点をリセット」で戻します。点が重なった語は「3Dで選ぶ語」から文脈を開けます。点の大きさは一定で、距離は意味の類似度ではありません。

時系列も3Dのまま再生でき、PNGは選択中の表示形式・視点・期間になります。表示切替・視点変更は再生を止め、取得や外部通信は始めません。保存済み本文だけを使います。「2D ミラー」で従来の表示に戻ります。

## 保存済み履歴を期間で見る

クラウド上部の「期間・時系列」で開始日・終了日を指定し、「期間を適用」を押します。「時系列を再生」は日／月ごとの集計を順番に表示し、「その期間だけ」「開始日から累積」を選べます。日付は日本時間・両端を含みます。2Dの文字サイズは各期間内で相対調整されます。3Dの点と文字のサイズは一定です。

取得を停止した状態で使用します。日付変更・再生・再解析は保存済みの本文だけを使い、ChatGPTへ追加取得しません。停止・タブを隠す・単語の文脈やPNGを開くと自動送りが止まります。停止直前に集計中だった1時点は完了して表示されます。全期間に戻す操作はデータを消しません。PNGは表示中期間の静止画です。

この文書は、本人が許可した個人アカウントで使う未公開のChrome拡張について説明します。通常のWeb版とは別ビルドです。公式連携ではありません。元サービスの仕様変更・アクセス制限・利用条件への適合確認は残る制約です。ソースコードのcommit・pushは2026-09-10に本人が明示的に許可しましたが、拡張ストア公開、配布、外部デプロイ、実データのアップロードは許可範囲に含まれません。

## 起動

ローカル作業コピーで実行します。

```sh
pnpm build:private
```

生成先は `dist-private/` です。通常Web版の `dist/` を置き換えません。

1. 本人がログイン済みのChromeで `chrome://extensions` を開きます。
2. 開発者モードを有効にし、「パッケージ化されていない拡張機能を読み込む」で、この作業コピーの `dist-private/` を選びます。
3. 同じChromeプロファイルでChatGPTを開きます。対象は本人の個人ワークスペースだけです。
4. 拡張機能の「Promptprint Private」を押すと、拡張専用の `private.html` が開きます。
5. 本人のChatGPTメールアドレスを入力し、「接続確認（本文3件）」または「接続して取得を開始」を押します。パスワード・トークン・Cookieの入力、JSONの保存やアップロードは不要です。

すでに読み込んである拡張をビルドし直した場合は、取得を停止してから `chrome://extensions` の更新ボタンを押し、個人用ページを再読み込みします。実際に稼働している個人用ページの正確なURLと検証状況は、リポジトリ外の私的ステータス報告で確認してください。Chrome拡張IDを他のプロファイルでも同じだと仮定しないでください。

## 取得と途中結果

- 標準目標は直近1,000**スレッド**。100 / 500 / 1,000 / 3,000を選べます。発言数とは別に表示します。
- 最初の25スレッドで可視化を開始し、以後は25本文以上の増加かつ30秒以上の間隔で更新します。停止・終了時は保存済みの最終本文を解析します。接続確認の3本文でも停止後の部分結果を表示します。
- 最新一覧は更新日時順を要求し、アダプターが確認できた順序を表示します。日時順を確認できない場合は未確認と表示します。元の発言日時を取得時刻で補いません。
- 一覧取得数、本文取得済みスレッド数、発言数、取得失敗、今回の目標内の未取得、経過時間を表示します。総数不明の進捗率は出しません。
- 未公開一覧APIの `total` は先読み値の可能性があるため、総数や終了条件に使いません。非空ページの次を確認し、空ページで今回の対応一覧の終端と判断します。終端での件数も全アカウントの履歴総数ではありません。取得中の元データ更新に対する一覧全体の固定スナップショットはありません。
- 日時順はページ内だけでなくページ境界でも検証し、逆転・不明日時があれば未確認とします。発言日時がない場合、既存の期間フィルターは会話の更新/作成日時を参照するため、表示期間は発言日時だけで確定した厳密な期間とは限りません。
- 一覧タイトルを本文取得成功に数えません。可視化は選択中の分岐の、通常表示されるuser/assistant本文を対象にします。tool/system/developer、非表示メッセージ、推論等の内部チャネルは除外します。
- 解析用テキストでは、ChatGPTの引用表示用制御構文 `U+E200 cite/filecite U+E202 … U+E201` を空白に置換します。対象は完全に閉じた既知マーカーで、参照部が1〜4,096 UTF-16コード単位、改行・入れ子なしの場合だけです。通常の単語 `cite`、未知の構文、未閉鎖・上限超過のマーカーは削りません。文脈用の原文は変更せず、出現回数と1,000トークンあたりの分母は同じ清掃済みトークン列から算出します。新しいプロバイダー構文は未対応のため語に残る場合があります。
- 画面の「解析済み」は現在の表示条件で解析した件数です。取得済み件数・解析Workerに読み込んだ件数とは区別します。日付等のフィルターで少なくなる場合があります。
- アーカイブ、プロジェクト、削除済み、共有先、別ワークスペース等を含む全履歴の網羅性は保証しません。一覧総数より少なく終了した場合も、全履歴取得済みとは表示しません。
- 取得と解析は別処理です。更新を待たずに単語の文脈、表示条件、非表示設定を使えます。フィルター変更と非表示処理は古い解析結果をキャンセルします。

## 停止・再開・消去

「取得を停止」は新たな取得を止め、取得済み本文と進捗を残します。開始済みの読み取り要求はブラウザ側で終わる場合がありますが、停止後に遅れた応答を保存・集計へ戻しません。タブを閉じると取得は止まります。短命な拡張popupやservice workerのメモリだけに取得進捗を置きません。

同じ拡張ページを再度開くと、保存済み対象アカウントの結果をローカルで復元できます。次に「取得を再開」を押すと、ログイン中のメールアドレス・個人アカウント・ワークスペースを再確認して続けます。同じ会話IDをupsertするため、再開で本文や発言を積み増しません。別アカウントへの切り替わりは停止理由です。

照合するメールアドレスを変更して接続する場合は、前のアカウントの解析Worker・図・文脈・PNG作成を破棄してから照合します。新しい接続が拒否された画面に、以前のアカウントの図を残しません。取得件数が同じでも本文更新・対象の選び直しでコーパスrevisionが変われば再解析し、古い結果を最新と表示しません。

401は通常の再ログイン待ちです。403やチャレンジは停止し、回避しません。429はRetry-Afterを尊重した有限回の待機・再試行です。停止後も部分結果を残します。失敗を再試行する場合もユーザーの再開操作が必要です。

「端末内の会話・進捗を全消去」→「全消去を実行する」で、取得・正規化・解析・PNG作成を停止し、この個人用拡張が保存した会話と進捗を全アカウント分削除します。遅れたレスポンスでデータを復活させません。ChatGPT側の履歴は変更しません。既にダウンロードしたPNGや手動で保存したスクリーンショットはブラウザから削除できないため、必要なら利用者が別途削除してください。

個人用ページを複数開いた場合はWeb Locksで取得と全消去を直列化します。全消去の通知は本文を含まない固定メッセージとして他の個人用タブへ送り、他のタブでも取得・Worker・PNG作成を停止して表示中の私的データを落とします。古いタブの応答を確認できず全消去のロックを取れない場合は、成功したと装わずエラーを表示します。

実際の元サービス読み取りには別の拡張オリジンのWeb Lockを使い、停止したローカル呼び出しの裏で処理が完了するまで次の要求を待たせます。待機中の認証確認・本文取得もキャンセルでき、通常の停止/再開や生存中の複数タブで読み取りが積み重なりません。拡張ページ自体を破棄するとブラウザがロックを解放し得るため、再読み込みを繰り返した場合の厳密な同時数上限は未検証です。開始済み処理には45秒の中止タイマーがあります。更新は取得停止後、少なくとも45秒待ってから行ってください。

## 保存と通信の境界

| 対象 | 個人用拡張 | 通常Web版 |
| --- | --- | --- |
| 会話取得 | 許可されたChatGPTタブ内でChatGPTへのGET | ローカルのZIP/JSON入力のみ |
| 本文の保存 | Chromeプロファイル内の拡張オリジン専用IndexedDB `promptprint-private-v1` | 永続保存なし |
| 本文の解析 | 専用Worker。本文は端末内 | 専用Worker。本文は端末内 |
| 再開情報 | アカウント・ワークスペース別のチェックポイント | なし |
| メールアドレス | 拡張オリジンの `promptprint-private:expected-email` とチェックポイント | 保存なし |
| 認証秘密 | ChatGPTタブの読み取り呼び出し内だけで使用。解析DBには保存しない | 取得・保存しない |
| 外部AI・運営サーバーへの本文送信 | なし | なし |

IndexedDBの本文は平文のローカル保存です。端末やChromeプロファイルを共有する利用者からの秘匿を保証するものではありません。必要に応じて個人プロファイルとOSのアカウント保護を使ってください。

PNGは共有のCanvas実装で、語と集計値だけを描きます。原文・タイトル・メールアドレス・非表示語を含めません。私用の取得方法と部分取得表示は、任意の文字列ではなく集計値から組み立てます。それでも図に出る語は実履歴由来なので非公開の成果物として保管してください。実データ・画像・ログ・認証状態はGitへ追加しないでください。

## 性能と検証の位置付け

本文正規化は専用Workerで行い、長いプロバイダーグラフの走査がUIを塞がないようにしています。解析WorkerはIndexedDBから本文を読み、React側には集計結果と必要最小限の文脈だけを返します。本文全件を毎回メインスレッドと往復させません。表示条件の再解析ではWorker内の本文を再利用できます。ただし取得チェックポイントの更新ではその時点の対象本文を読み直して全体集計するため、数千の長い会話での総時間とメモリ使用量には上限があります。上限・除外は取得件数とは分けて診断します。

実行する検証:

```sh
pnpm check
pnpm build:private
pnpm e2e
pnpm e2e:private
```

ユニットテストは合成データで取得ページ送り、本人照合、分岐、重複、停止・再開、429等の再試行、全消去後の遅延応答、表示更新の抑制とWorkerメッセージの本文非複製を確認します。通常Web版のネットワーク・ストレージ・PNG・コンソール保護テストは維持します。

個人用E2Eは一時的な合成専用Chromeプロファイルへ実際の未パッケージ拡張を読み込み、元サービス応答を合成fixtureに限定して実行します。本人のChromeプロファイルや実履歴には接続しません。390×844の表示確認はデスクトップChromeを狭くしたレスポンシブ検証であり、Android/iOSへの拡張対応を意味しません。画像はリポジトリ外の私的テスト領域へ保存します。
